PROJECT GOAL
Clarify the boundaries. Agentic API does not replace vLLM or llm-d. It adds the stateful API and tool loop coding harnesses expect. The project goal is one API that works on a single local node and scales to distributed Kubernetes. llm-d remains the serving and routing layer; vLLM remains the inference engine.

Agentic APIs are becoming server-side runtimes.

Decouple responsibilities

State CRUD and tool execution belong in the Agentic API; vLLM remains focused on token generation.

OpenAI describes Responses as stateful by default, with conversations and tool state tracked automatically. The point for an open stack is architectural: response CRUD and tool execution should not be fused to token generation. The CAIS figure shows why the API surface naturally spans state, retrieval, providers, and tools. vLLM's GPT-OSS recipe already exposes the Responses API and tool use, while also calling out the remaining implementation surface. This is the path we actually ran. Claude Code and Codex spoke different public protocols but entered the same Agentic API. Agentic API owned SQLite state, streaming, and server-side web search. On CoreWeave it called the vLLM ClusterIP Service directly, which reached one Qwen3-8B pod on one H100. The local KinD setup used the same direct shape with vLLM exposed on port 5050. There was no routing layer between Agentic API and vLLM in this demo.

Next: disaggregated Responses

The response lifecycle becomes its own scalable system.

INFERENCE-PROVIDER NEUTRALINDEPENDENT SCALINGOPEN PROTOCOLS

Response execution plane

State, memory, streaming, tool loops, approvals, continuation.

Inference plane

llm-d routes across vLLM today, with a neutral seam for other providers.

Learning plane

Replayable trajectories, evaluations, and eventually RL environments.

Disaggregated Responses means separating response execution from model inference. State and tools can scale on their own cadence; llm-d and the inference backend can optimize model serving; future evaluation and RL systems can consume the response trajectory.
